# Benachrichtigungen

- Jede Person bekommt eine Nachricht, wenn etwas sie betrifft: Zuweisung, eigenes Gewerk betroffen, Statuswechsel, Frist nah oder überfällig, Kommentar oder Erwähnung.
- **Einstellbar pro Person:** Kanal (Push, E-Mail), sofort oder als Tageszusammenfassung, nach Projekt, Modul und Priorität.
- **Dringendes** (Verzug, Freigabe nötig) lässt sich nicht stummschalten.
- Zentrale **Mitteilungszentrale** in der App (offen / erledigt).

## Beispiele
| Ereignis | Empfänger |
|---|---|
| Polier meldet Bedarf | Einkauf |
| Bestellung bestätigt | Polier |
| Lieferung angemeldet | Bauleitung |
| Lieferung bestätigt | NU |
| NU-Besprechungsvorschlag „Dringend“ | Bauleitung (sofort) |
| Bemusterung nicht rechtzeitig entschieden, Standardoption greift | alle Beteiligten |
