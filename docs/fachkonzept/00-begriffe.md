# Begriffe

| Begriff | Bedeutung |
|---|---|
| **NU** | Nachunternehmer (extern). Sieht nur eigene Gewerke und Aufträge. |
| **Gewerk** | Leistungsbereich (Elektro, Fliesen, Estrich …), einem oder mehreren NU zugeordnet. |
| **Ort** | Hierarchie Projekt → Gebäude → Geschoss → Abschnitt → Raum (rekursiv). |
| **Index** | Versionsbuchstabe eines Plans (A, B, C …). |
| **Freigabe** | Protokollierte Entscheidung einer berechtigten Person, danach unveränderlich. |
| **Alt** | Unterordner in jedem Ordner für ersetzte Stände. |
| **Bemusterung** | Auswahlentscheidung zu Material oder Produkt aus einem Katalog (Standardausstattung mit Optionen). |
| **Allowance** | Optionales Budget pro Bemusterungsposten. |
| **Regie** | Stundenlohnarbeit, braucht eine vorherige Anordnung. |
| **Nachtrag** | Zusatzbeauftragung zu einem Auftrag, erst nach Beauftragung abrechenbar. |
| **Polier** | Vorarbeiter auf der Baustelle (eigenes Personal). |
