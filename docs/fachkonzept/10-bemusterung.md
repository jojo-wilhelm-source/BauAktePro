# Bemusterung

## Standardausstattung mit Auswahl
- Ein Katalog pro Projekt, Posten mit je 2–5 Optionen (Foto, Hersteller, Artikelnummer, Datenblatt, Preis, Lieferzeit).
- Pro Posten wird festgelegt, wo er gilt (z. B. alle Bäder OG 1–3).
- Kataloge dienen als Vorlage für neue Projekte.
- **Frist** aus dem Bauzeitenplan: Vorgangsstart minus Lieferzeit.
- Optionale **Standardoption** als Voreinstellung, falls nicht rechtzeitig entschieden wird (mit Hinweis an alle).

## Allowance
- Optional pro Posten, mit eigenem Schalter **„für Bauherr sichtbar“**.
- **Nicht sichtbar:** Der Bauherr sieht keine Preise und keine Mehrkosten. Intern wird die Differenz trotzdem berechnet und kann als Nachtrag laufen.
- **Sichtbar:** Der Bauherr bestätigt die Mehrkosten vor der Entscheidung.

## Entscheidung
- Im Bauherren-Portal (Standard) oder per Einmal-Link (abschaltbar).
- Protokolliert (Person, Zeit, Option, Bestätigung), danach gesperrt.
- Änderungswünsche danach: Prüfung auf Mehrkosten und Termin; betroffene Pläne gehen auf „Prüfung erforderlich“.

## Ablauf
```
Angelegt → Optionen vorgelegt → Entschieden → Bestellfreigabe an Einkauf → Bestellt → Geliefert → Eingebaut/abgenommen
```

## Verknüpfungen
Pläne (automatische Bauherr-Freigabe), Bauzeitenplan, Einkauf (Bestellvorlage), Nachträge, Mängel/Abnahme (verbaut gegenüber Entscheidung), Dateiablage.

## Weiteres
Musterverwaltung (Standort, Rückgabe), Bemusterungstermine, Musterflächen.
